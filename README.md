# AI VIDEO STUDIO PRO

واجهة استوديو فيديو عربية (RTL) بتصميم داكن ولمسات ذهبية.

## الأدوات الموجودة
- مساحة العمل وVideo Timeline الأساسي وSmart Auto Montage.
- Video Trimmer وVideo Merger باستعمال FFmpeg.wasm.
- Audio Studio: فيديو + موسيقى + تعليق صوتي + تحكم في مستويات الصوت.
- تسجيل التعليق الصوتي مباشرة من الميكروفون (يتطلب HTTPS وإذن الميكروفون).
- Text to Video: تقسيم النص إلى مشاهد، صورة اختيارية لكل مشهد، وتصدير WebM من المتصفح.
- Image to Video: تحريك الصور بتأثيرات تقريب/إبعاد/تحريك جانبي وتصدير WebM.

## التشغيل
1. افتح المشروع عبر خادم محلي (VS Code Live Server) أو انشره على GitHub Pages.
2. استعمل Chrome أو Edge حديثاً.
3. من Video Trimmer اضغط «تحميل محرك المونتاج» لتحميل FFmpeg؛ الأدوات التي تعتمد عليه تستعمل نفس المحرك.
4. تسجيل الميكروفون يحتاج موقعاً آمناً HTTPS أو localhost مع السماح بالوصول للميكروفون.

## ملاحظات تقنية مهمة
- Text to Video في هذه النسخة ينشئ فيديو مشاهد من النصوص وصور المستخدم (مع حركة كاميرا)، ولا يدّعي توليد مشاهد AI جديدة من الصفر.
- Image to Video يطبق حركة Ken Burns على الصور؛ التوليد الحركي الحقيقي بالذكاء الاصطناعي يحتاج نموذجاً خارجياً أو خدمة API.
- إنشاء Text/Image-to-Video من المتصفح يصدّر WebM حسب دعم المتصفح. يمكن استيراد الناتج في Audio Studio لإضافة الصوت؛ تصدير MP4 عبر FFmpeg.
- FFmpeg.wasm قد يكون ثقيلاً على الأجهزة ذات الذاكرة المحدودة، لذلك يفضّل معالجة مقاطع قصيرة وبدقة 720p عند الحاجة.
- لا توجد خدمة سحابية أو اشتراك مدفوع مدمج في المشروع.
